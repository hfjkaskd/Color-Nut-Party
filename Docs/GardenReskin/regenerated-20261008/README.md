## 来源与含义

左侧分为原版Android设备截图和换皮前Unity还原截图，逐页明确标注；没有将旧版换皮截图冒充原游戏。设备图来源是 `reconstruction-nut/reward-device-evidence`，已有采集记录见 `Docs/RewardEvidence/README.md`。旧Unity截图主要来自 `Library/ValidationCaptures` 和 `Docs/RewardEvidence`。

右侧全部为内置 ImageGen 新生成的AI美术效果图，不是Unity运行截图，也不是已替换工程结果。各张沿用其原图金额、地区和关卡状态，因此不同页面可能显示不同币种或数值。

撤销、加螺丝没有单独保存的换皮前运行截图；这两页左侧明确标记为“换皮前共享道具弹窗（刷新态）”。右侧变体文案与图标按现有ItemGetPanel及原文本配置生成：Undo / Undo last action；Bolt+ / Add an empty bolt。没有冒称左图为这两态的原截图。

新玩法说明选用隐藏螺母作为代表状态。设置入口没有对应的独立设置Prefab，本轮未凭空新增设置界面。静态图不包含动画每帧或金额变化的所有排列。

## 复核与可追溯性

逐页检查文字边界、可见按钮数量、奖励语义、关键金额与原图对应关系；核心页面经过另一代理独立复核。生成过程中发现的多余HUD、数字、旧粉色底板、奖励局部遗漏与位置偏移，分别做定向修正。未使用AI美化原游戏截图。

每页保存提示词及 `generation-*.json` 或 `*-generation.json`。修正记录保存在 `correction-*.json` 与相关提示词。生成方式均为内置ImageGen，不使用CLI。`comparison-manifest.json` 记录最终图与原图SHA-256和尺寸；原图副本逐字节保留。对比脚本仅进行等比缩放、添加来源标签和排版，不绘制或篡改截图内容。

这些图用于确认美术方向；AI绘制不能替代像素级Prefab或真机验收。后续实施应继续沿用现有节点和布局，以Unity实际运行截图单独验收。
